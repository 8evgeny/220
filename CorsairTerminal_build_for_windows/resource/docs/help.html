Клавиатура

  • Объектив

    • "Q" "W" - zoom
    • "A" "S" - focus
    • "Z" "X" - iris
    • "F" - автофокус

  • Изображение

    • "E" "R" - электронное увеличение от 1 до 4 крат
    • "T" - режим "картинка в картинке"
    • "F9" "F10" - программная яркость
    • "F11" "F12" - программный контраст
    • "N" - вкл/выкл аппаратного АРУ
    • "M" - программная инверсия

  • Дальномер

    • "L" - разрешение измерений
    • "K" - выбор режима дальномера
    • "Enter" (NumPad) - измерение

  • Трекер

    • "D" - разрешение/запрет захвата
    • "ESCAPE" - отмена захвата/запрет захвата

  • Разное

    • "F1" - вывод справки
    • "F2" - вывод телеметриим
    • "F7" - сделать снимок
    • "F8" - включить/выключить запись видео
    • "Tab" - полноэкранный режим
